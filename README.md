# Windyke Points Card (OTH)

Stableford points scorecard for Windyke CC (West and East) with Golf Bunch targets.

- `index.html` is the whole app (GitHub Pages serves it).
- `targets.json` holds player targets. A GitHub Action (`.github/workflows/update-targets.yml`) refreshes it from the Golf Bunch targets page at 0700 and 1800 Central. Run it on demand from the **Actions** tab → **Update targets** → **Run workflow**.
